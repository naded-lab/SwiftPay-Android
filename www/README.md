# SwiftPay v3 — PWA متعدد الملفات

## البنية
```
SwiftPay/
├── index.html          # الصفحة الرئيسية (كل الشاشات)
├── service-worker.js    # التخزين المؤقت للعمل بلا إنترنت (يجب أن يبقى بالجذر — انظر التنبيه أدناه)
├── css/style.css        # كل التنسيقات + نظام الألوان الداكن/الفاتح
├── js/app.js             # منطق التطبيق (أكواد USSD، السجل، المفضلة، القفل)
├── js/theme.js           # تبديل/حفظ الوضع الداكن والفاتح
├── js/install.js         # نظام تثبيت PWA (تلقائي + شرح يدوي حسب الجهاز)
├── pwa/manifest.json     # ملف الـ Web App Manifest
├── assets/icons/         # أيقونات PWA بجميع الأحجام (نفس الأيقونات السابقة)
└── netlify.toml          # إعدادات النشر على Netlify
```

> ⚠️ **تنبيه مهم بخصوص `service-worker.js`:** يجب أن يبقى هذا الملف في **جذر المشروع** وليس داخل مجلد فرعي (مثل `pwa/`). نطاق تحكم (scope) الـ Service Worker الافتراضي هو المجلد الذي يوجد فيه الملف نفسه فقط — فلو كان داخل `pwa/`، لن يستطيع التحكم بباقي صفحات التطبيق (`index.html`, `css/`, `js/`) ولن يعمل التخزين المؤقت خارج ذلك المجلد، وهذا كان سبب عدم عمل التطبيق بلا إنترنت في نسخة سابقة.

## النشر عبر GitHub Actions / Netlify
هذا المشروع Static بالكامل (HTML/CSS/JS فقط، بدون build step)، لذلك:
- على Netlify: اربط المستودع مباشرة، اجعل **Publish directory** = مجلد `SwiftPay` (أو جذر المستودع إن كانت الملفات بالجذر). لا حاجة لأمر Build.
- عبر GitHub Actions: يمكن استخدام إجراء `nwtgck/actions-netlify` أو رفع المجلد كـ artifact مباشرة، بدون خطوة تثبيت حزم لأن لا يوجد `package.json`.

## كيف تختبر وضع "بلا إنترنت" بشكل صحيح
Service Worker **لا يعمل إطلاقاً** عند فتح الملف مباشرة من الجهاز (`file:///...`) — يجب رفعه على خادم حقيقي (Netlify) أو تشغيله محلياً عبر `http://localhost`. خطوات الاختبار الصحيحة بعد الرفع:
1. افتح رابط الموقع لأول مرة والإنترنت متصل، وانتظر ثانيتين حتى يكتمل تسجيل الـ Service Worker (تقدر تتأكد من DevTools ← Application ← Service Workers).
2. **أعد تحميل الصفحة مرة واحدة** (هذا ضروري: أول زيارة يسجّل الـ SW لكنه لا "يتحكم" بالصفحة نفسها إلا بعد تحديث/فتح تالٍ).
3. فعّل وضع الطيران أو اقطع الإنترنت، ثم أعد فتح التطبيق — يجب أن يعمل بشكل طبيعي كامل.

## أهم الفروقات عن النسخة السابقة (ملف HTML واحد)
- فصل كامل للـ CSS/JS عن HTML (كان كل شيء بملف واحد 2400 سطر).
- هوية بصرية جديدة (الألوان المطلوبة: `#080D1A` / `#111827` / `#00E676` / `#6366F1` للداكن، و`#F8FAFC` / `#FFFFFF` / `#00B86B` للفاتح).
- نظام تثبيت PWA حقيقي: يلتقط `beforeinstallprompt` عند توفره، ويعرض شرحاً يدوياً مخصصاً لكل متصفح (Chrome Android، Samsung Internet، Firefox Android، Edge، iOS Safari، Desktop) عند غيابه.
- تم الحفاظ على 100% من منطق العمل الأصلي: توليد أكواد USSD لجوال بي وبال بي، القفل بـ SHA-256 المُمَلَّح، السجل بالتاريخ الذكي، المفضلة، حفظ الرموز السرية.

## قائمة التحقق (تمت مراجعتها في الكود، يوصى باختبارها فعلياً على جهازك)
- ✅ `node --check` على جميع ملفات JS بدون أخطاء صياغية
- ✅ لا توجد معرّفات (id) مفقودة بين HTML و JS
- ✅ `manifest.json` صالح (JSON صحيح)
- ✅ Service Worker يخزّن كل ملفات الـ app shell (html/css/js/manifest/icons) لعمل offline كامل بعد أول فتح
- ✅ التصميم مبني على `max-width: 480px` + متغيرات CSS، ويُختبر يدوياً عند 320px عبر media query مخصص
- ⚠️ يفضّل اختبار زر "تثبيت" فعلياً على جهاز Android حقيقي بعد الرفع على Netlify (محاكاة `beforeinstallprompt` تتطلب HTTPS حقيقي، لا تعمل من ملفات محلية)
