# نسخة SwiftPay — الويب/Capacitor

واجهة HTML/CSS/JS (في `www/`) معروضة داخل WebView عبر جسر
[Capacitor](https://capacitorjs.com)، مع إضافة Kotlin مخصّصة (`native-stage2/UssdPlugin.kt`)
لتنفيذ أكواد USSD مباشرة وقراءة رد الشبكة برمجياً.

## البنية

- `www/index.html` — الهيكل والمودالات (تفاصيل التحويل، المفضلة، خيارات العملية...)
- `www/css/style.css` — كل الأنماط، بما فيها الوضع الداكن ومتغيرات الألوان في `:root`
- `www/js/app.js` — منطق التطبيق: المعالج (Wizard)، السجل، المفضلة، تصنيف رد USSD
- `www/js/keyboard.js` — إخفاء الشريط السفلي تلقائياً عند ظهور لوحة المفاتيح
- `www/js/boot-guard.js` — شاشة بديلة عند حدوث خطأ JS غير متوقع بدل شاشة فارغة صامتة
- `www/js/install.js` — منطق "أضف للشاشة الرئيسية" لمتصفحات الويب العادية
- `native-stage2/UssdPlugin.kt` — الإضافة الأصلية لتنفيذ USSD (Android 8+ فقط)

## لماذا `native-stage2/` منفصل عن `www/`؟

لأن `npx cap add android` يُنشئ مشروع أندرويد قياسي بدون أي إضافات مخصّصة.
`native-stage2/UssdPlugin.kt` + سكربت `install-stage2.sh` يحقنان الإضافة
والأذونات والعلامة التجارية (الأيقونة وشاشة البداية) في المشروع المتولّد بعد
إنشائه مباشرة. هذا هو نفس السكربت المستخدم في `setup.sh` المحلي وفي GitHub
Actions — وصفة واحدة، مكان واحد، لا تكرار.

## البناء محلياً

```bash
./setup.sh
cd android
./gradlew assembleDebug
```

(مجلد `android/` مُتولَّد تلقائياً بهذا السكربت ولا يُحفظ في git — راجع README الرئيسي.)

## ملاحظات تصميم مهمة

- **الشاشة البيضاء عند الكتابة**: تم التعامل معها عبر `js/keyboard.js`
  (يراقب `visualViewport` ويفرض إعادة رسم عند تبدّل ارتفاع لوحة المفاتيح) +
  `android:configChanges` على نشاط Capacitor لمنع إعادة إنشائه. راجع تعليقات
  الكود في `keyboard.js` لفهم آلية الحماية بالتفصيل.
- **تصنيف رد USSD تلقائياً**: `classifyUssdResponse()` في `app.js` يطبّع النص
  (أرقام عربية، تشكيل) ويقارنه بقاموس أنماط نجاح/فشل شائعة. لا يُسأل المستخدم
  "هل نجحت العملية؟" إلا إذا تعذّر التصنيف تماماً.
- **سجل العمليات**: مُجمّع حسب اليوم (`renderHistory()` في `app.js`)، والضغط
  على أي عملية غير معلّقة يفتح خيارات حذف/إعادة (`openTxActions()`).
- **الأيقونة وشاشة البداية**: مصدرها `branding/` في جذر المستودع (كل
  الكثافات + خلفية الأيقونة التكيّفية). لتغيير الشعار، استبدل الملفات هناك
  فقط ثم أعد التشغيل — لا تُعدّل داخل `android/` لأنه يُستبدل بالكامل عند كل توليد.
