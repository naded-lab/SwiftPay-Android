# أرشيف نسخة SwiftPay Native (Java/XML)

تم أرشفة هذه النسخة بتاريخ 2026-09-06 بعد قرار معماري بالتوحيد على نسخة
الويب/Capacitor (`www/`) كمصدر وحيد للحقيقة (Single Source of Truth).

## سبب القرار

- كل الميزات المطلوبة (مودال المفضلة، تصنيف USSD التلقائي، سجل مُجمّع حسب
  اليوم مع خيارات حذف/إعادة...) كانت مبنية بتصميم أنضج في `www/` أصلاً؛
  نسخة Native كانت تحتاج إعادة بناء كل شيء تقريباً من الصفر لتصل لنفس المستوى.
- الحفاظ على تطبيقين متوازيين (Native + Web) يضاعف كل جهد صيانة مستقبلي.
- منطق تصنيف رد USSD (`classifyUssdResponse`) وربطه بإضافة Kotlin
  (`native-stage2/UssdPlugin.kt`) كان الأساس الأنسب للبناء عليه، وهو خاص
  بنسخة Capacitor أصلاً.

## المحتوى

- `android/` — كامل مشروع Gradle الأصلي (Java/XML، بدون WebView) كما كان قبل
  الأرشفة، شغّال ومكتمل بذاته إن احتجت الرجوع إليه أو استخراج أي منطق منه.
- `build-apk.yml.bak` — سير GitHub Actions الذي كان يبني هذه النسخة (معطّل
  الآن، أُعيدت تسميته بامتداد `.bak` حتى لا يعمل GitHub Actions تلقائياً).

## هل يمكن استعادتها؟

نعم — انسخ `android/` إلى جذر المستودع، وأعد تسمية `build-apk.yml.bak` إلى
`build-apk.yml` داخل `.github/workflows/`. لكن لاحظ أنها ستحتاج نفس التحديثات
التي طُبّقت على نسخة الويب لاحقاً (لن تُزامَن تلقائياً بعد الأرشفة).

## أين انتقلت أيقونات هذه النسخة وشاشة بدايتها؟

نُقلت إلى `branding/` في جذر المستودع (مصدر العلامة التجارية الوحيد الآن)
قبل الأرشفة، ليستمر استخدامها في نسخة Capacitor عبر
`native-stage2/install-stage2.sh`.
